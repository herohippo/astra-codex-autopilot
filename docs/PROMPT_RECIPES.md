# 대화 예시

## 앱 안에서 계속하기

```text
$astra-autopilot 앱 모드로 현재 프로젝트 작업을 이어가줘.
지금까지 합의한 요구사항과 남은 일을 먼저 파일에 정리해줘.
완료 기준: README의 실행 방법대로 동작하고 관련 테스트가 통과할 것.
이 작업에 자동 재실행을 연결하고 완료 또는 개입이 필요할 때 알려줘.
```

## CLI 작업으로 맡기기

```text
$astra-autopilot 이 프로젝트를 CLI 백그라운드 모드로 시작해줘.
자동 작업은 현재 저장소 범위에서 진행하고, 목표와 다음 단계를 저장해줘.
먼저 doctor로 환경을 확인한 뒤 start하고 중지 방법을 알려줘.
```

## 중지와 재개

```text
이 프로젝트의 자동 작업을 일시정지해줘.
현재 실행도 즉시 멈춰줘.
멈춰둔 작업을 같은 모드로 재개해줘.
```

앱에서는 자동화 일시정지와 현재 차례의 Stop이 구분됩니다. CLI에서 즉시 중지는 `stop --now`입니다. 파일 변경은 자동으로 취소하지 않습니다.

## 방향 바꾸기

```text
지금 기능 추가는 보류하고 로그인 오류 수정과 회귀 테스트를 우선해줘.
기존 완료 기준에 키보드 접근성 검증도 추가해줘.
```

## 앱에서 CLI로 전환

```text
앱 자동화를 일시정지하고 현재 작업이 멈췄는지 확인한 뒤,
체크포인트를 저장하고 CLI 백그라운드 모드로 전환해줘.
```

앱 스케줄러가 제공되지 않는 환경에서 앱 모드를 설정했다고 보고하지 않습니다. 원하는 경우에만 CLI 모드로 전환합니다.

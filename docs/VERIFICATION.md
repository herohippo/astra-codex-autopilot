# v0.2.0 검증 기록

로컬 검증 환경: Windows, Python 3.13, Codex CLI 0.154.0.

- pytest: **40개 통과**. 실제 모델 호출 없이 가짜 Codex 자식 프로세스로 검증했습니다.
- 포함 범위: 한도 오류 후 대기·성공·완료, 저장된 대기 시각 복원, 백그라운드 중복 실행 방지, 정상/즉시 중지, 자식 프로세스 종료, 실행 중 추가 지시 보존, 인증 확인, 출력 상한, 실행 횟수 제한, 앱 소유권·중지·자동화 연결 보호.
- 추가 회귀 검증: 대상 프로젝트의 Python 패키지가 supervisor를 가로채지 못함, 시작 취소 시 백그라운드 프로세스 정리.
- plugin-creator manifest 검증과 skill-creator 스킬 검증 통과.
- 배포용 manifest·스킬 참조·실행 진입점 4개 검증 통과.
- Python wheel 빌드와 MIT LICENSE 포함 확인.
- 실제 사용자 환경에서 Codex CLI의 ChatGPT 로그인 상태 확인. 인증 정보는 읽거나 배포하지 않았습니다.

미검증 범위: 실제 계정의 할당량 소진부터 복구까지 이어지는 장시간 실행, 호스트 앱 heartbeat의 실제 한도 복구 주기, macOS 실행. Linux 및 다른 Python 버전은 GitHub CI 결과를 별도로 확인해야 합니다.

앱 도우미 테스트 통과는 호스트 스케줄러의 자동 재시도 보장을 뜻하지 않습니다. 앱 스케줄러 기능 제공 여부와 실행 조건은 사용자 환경에 따라 달라집니다.
